Step 01

Get the extension

ClickSafe isn’t on the Chrome Web Store yet — but you can load it directly from the GitHub repo in under a minute. No store required.

1

Clone or download the repo

Grab the source from GitHub. You only need the frontend/ folder to run the extension — the rest is backend.

View on GitHub
git clone https://github.com/reshmi-git/clicksafe-browser-extension-project
2

Open the Extensions page in Chrome

Paste chrome://extensions into your address bar and hit Enter. Then toggle on Developer mode using the switch in the top-right corner.

chrome://extensions → Developer mode → ON
3

Load the unpacked extension

Click Load unpacked (appears after enabling Developer mode) and select the frontend/ folder from the cloned repo. ClickSafe will appear in your extensions list immediately.

Load unpacked → select /frontend folder
Permissions explained

ClickSafe requests access to read browsing activity and manage downloads. This is needed to scan links and intercept files before they hit disk. No data ever leaves your browser.

4

Confirm it’s running

You should see the ClickSafe card in chrome://extensions with a blue toggle switched on. The red shield icon will also appear in your toolbar — if it’s hidden, click the puzzle-piece icon to find and pin it.

Step 02

Verify the install

Once installed, take 10 seconds to make sure everything is running correctly before you start browsing.

1

Check the toolbar icon

Look for the red shield icon in your browser's toolbar (top-right area). If you don't see it, it may be hidden — click the puzzle piece icon to find and pin it.

2

Open the side panel

Click the ClickSafe icon in the toolbar. A side panel slides open with your current page's Privacy Score, active trackers, and HTTPS status. If you see this, you're fully protected.

3

Navigate to any site

Try going to any website. Watch the Privacy Score in the side panel update in real time as the page loads. Numbers dropping? That means trackers were found — and blocked.

What a healthy score looks like

A score of 80–100 means the page has no trackers, is served over HTTPS, and has no mixed content. Most major news sites score 40–65 due to advertising trackers.

Step 03

Using ClickSafe

ClickSafe works automatically — you don't need to do anything for most protections. Here's what each part does and when it speaks up.

Always-on · Zero config
HTTPS Upgrades

Every HTTP connection is silently upgraded. You'll never see an insecure site if a secure version exists.

Tracker Blocking

70k+ tracker domains blocked on every page load. The Privacy Score reflects how many were caught.

Dark Patterns

Fake urgency timers, confirm-shaming, and pre-ticked boxes are highlighted inline on the page.

01

Dangerous Link Warnings

When you click a link that matches a known phishing or malware domain, ClickSafe intercepts the navigation and shows a warning page. You can still proceed — it's your choice.

Triggered on click · SHA-256 local check
02

Download Interception

Every file you download is scanned for malware signatures before it's written to disk. If a threat is detected, the download is blocked and you'll see an alert.

Pre-disk · Fails closed on threat
03

Privacy Dashboard

Click the ClickSafe toolbar icon to open the side panel, then hit Full Dashboard. You'll see charts of trackers over time, company data profiles, and your full scan history.

Toolbar icon → Full Dashboard
04

Site Whitelist

Trust a site? Open the side panel and click Settings → Whitelist. Whitelisted domains skip tracker checks and won't be warned on. Useful for internal tools or trusted apps.

Side panel → Settings
Step 04

Pin & configure

Get ClickSafe one click away and tune it to how you work.

1

Pin the icon to your toolbar

Click the puzzle piece icon in Chrome's toolbar to see all installed extensions. Find ClickSafe and click the pin icon next to it. The red shield will now always be visible.

Toolbar → Puzzle piece → ClickSafe → Pin
2

Open Settings

Click the shield icon → Side panel opens → Click the gear icon in the top-right corner of the panel. This opens the full Settings page.

3

Adjust your preferences

From Settings you can toggle individual features on/off, manage your whitelist, adjust warning sensitivity, and optionally create an account to sync data across devices.

Optional: Create an account

An account lets you sync your whitelist, Privacy Score history, and settings between browsers. It's optional — ClickSafe works fully offline without one.

Troubleshooting

Something not working?

Most issues clear up in under a minute. Try these first.

Click the puzzle-piece icon (Extensions menu) in Chrome's toolbar. Find ClickSafe in the list and click the pin icon to make it permanently visible. If ClickSafe isn't in the list at all, the install didn't complete — try reinstalling from the Web Store.

Try closing the side panel and reopening it by clicking the ClickSafe icon again. If it stays blank, go to chrome://extensions, find ClickSafe, click the reload button, then re-open the panel. This usually fixes loading issues after a browser update.

The Privacy Score updates after the page fully loads. Try waiting a moment or doing a hard refresh (Ctrl+Shift+R). On pages with heavy JavaScript, scoring can take 1–2 seconds. If it consistently shows 0 on all sites, try disabling and re-enabling the extension in chrome://extensions.

Open the ClickSafe side panel on that site, go to Settings → Whitelist, and add the domain. Whitelisted sites skip all tracker checks and won't trigger warnings. You can remove them at any time from the same settings screen.

In Edge, go to edge://extensions and make sure ClickSafe is toggled on. Edge may also require you to explicitly allow extensions from other stores — look for the "Allow extensions from other stores" banner in the extension page and enable it.
