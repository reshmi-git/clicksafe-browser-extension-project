Installation Setup

Get ClickSafe running
in under a minute.

ClickSafe isn't on the Chrome Web Store yet. Load it directly from the source — takes four steps.

Steps
01 — Download 02 — Developer Mode 03 — Load Extension 04 — Confirm
Step 01

Download the source

Go to the GitHub repo and download the project as a ZIP file. Extract it anywhere on your computer.

View on GitHub
Step 02

Enable Developer Mode

Open Chrome and go to chrome://extensions in the address bar. Toggle on Developer mode using the switch in the top-right corner.

Step 03

Load the extension

Click Load unpacked — this button appears once Developer mode is on. Select the frontend folder from the extracted project.

Load unpacked → select /frontend
Step 04

Confirm it's running

The ClickSafe shield icon will appear in your Chrome toolbar. Click it to open the side panel — if you see your Privacy Score, you're protected.

If the icon is hidden, click the puzzle-piece menu in the toolbar and pin ClickSafe.

That's it. You're protected.

ClickSafe runs automatically on every tab from here on.
